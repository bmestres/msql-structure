# MySql Data structures

**Description:** <br>

The project contains a series of simple relational databases built using MySQL. Each database contains a relational model as well as the .sql scripts.


**Technologies used:**<br>
- Database: SQL
- Modeling: MySql Workbench
- Version control: Git & GitHub


**Installation and Execution:**<br>
https://github.com/bmestres/msql-structure.git

**How to run:**<br>
Import/Run the files in this order for each project:

**Schema:** Run the schema.sql files to build the table structures.

**Seed:** Run the seed.sql file to populate the database with dummy data.

**Queries:** queries.sql file to test specific business requirements.



### Project structure

**1. GlassesOpticDB:**<br>
Database schema for an optical store, with inventory and clients databse.

**2. PizzaParlourDB:**<br>
Database for a pizza delivery chain managing orders, employees, and locations.

**3. YouTubeDB:**<br>
Symplified schema for a video streaming platform with video publishing, user interactions and subscriptions.
